# Learn Playwright Batch 2X

A learning repository for understanding **JavaScript fundamentals and Playwright automation** step by step. The repository is organized into chapters, with each chapter covering specific JavaScript concepts and programming fundamentals required for browser automation and test automation.

## Topics Covered

The repository currently contains the following chapters:

### Chapter 01 – Basics

Introduction to JavaScript basics and fundamental programming concepts.

Topics include:

* Basic JavaScript syntax
* Console usage
* Introduction to JavaScript programs
* Basic programming examples

### Chapter 02 – JavaScript Concepts

Covers important JavaScript concepts and development practices.

Topics include:

* JavaScript fundamentals
* Basic language concepts
* VS Code shortcuts
* Writing and executing JavaScript programs

### Chapter 03 – Identifiers and Literals

Introduces identifiers and literals used in JavaScript programs.

Topics include:

* Identifiers
* Naming rules
* Keywords
* Literals
* Different types of values

### Chapter 04 – Variables

Covers the fundamentals of variables in JavaScript.

Topics include:

* Variable declaration
* `var`
* `let`
* `const`
* Assigning values
* Working with variables

### Chapter 05 – Functions

Introduces functions and their usage in JavaScript.

Topics include:

* Function declaration
* Function calls
* Parameters
* Arguments
* Return values
* Reusable blocks of code
